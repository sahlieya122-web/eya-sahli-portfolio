# Eya Sahli — Engineering Portfolio

A clean, light, responsive portfolio focused on RF, signal processing, embedded systems and applied AI.

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Build

```bash
npm run build
npm start
```

## Edit content

Most portfolio content lives in:

- `data/portfolio.js`

The main page is:

- `app/page.js`

Global styling is:

- `app/globals.css`

Profile photo:

- `public/eya-sahli.png`

## Deploy

This project is compatible with Vercel. Import the repository into Vercel and deploy with the default Next.js settings.
